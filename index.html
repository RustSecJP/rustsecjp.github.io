RustSecJP

Rust のエコシステムを、より安全に。

日本の Rust セキュリティ研究・情報共有コミュニティ。脆弱性の調査と分析、OSS への貢献、セキュリティの知見の共有に取り組んでいます。

非公式のコミュニティです。RustSec・Rust Project・Rust Foundation とは提携していません。

02 / 研究

研究と成果

取り組んでいる 3 つの領域です。公開できる成果があるものだけを載せ、まだ無い領域は空のままにしています。

サプライチェーンの安全性

依存クレート、ビルド環境、公開の仕組みの安全性。悪意のある crate の手口と、その見つけ方。

公開中 ・ RSJP-C-2025-001 ・ incidents

unsafe Rust とメモリ安全性

unsafe なコードの健全性、メモリ安全性、未定義動作。Miri やファジングで確かめたうえでの報告。

公開物はまだありません

脆弱性の調査

OSS の脆弱性の調査、ソースコードの解析、再現と検証。上流への報告と協調的な開示。

公開物はまだありません
